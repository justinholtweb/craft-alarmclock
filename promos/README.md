# Plugin Store promo images

Marketing images for the Alarm Clock listing on the Craft Plugin Store, rendered in the same theme
as the plugin's marketing page at
[justinholt.com/plugins/craft-alarmclock](https://justinholt.com/plugins/craft-alarmclock).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `alarmclock-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome,
then downsampled so the type stays crisp).

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, price | — |
| 2 | `entry.status = live` → everything else | the whole pitch, in one line |
| 3 | Three triggers, one ledger | which one wins, and why the database decides |
| 4 | Clears exactly what went stale | the tags a listing query registered |
| 5 | Retries the half that failed | task rows with their own attempt counts |
| 6 | Replace what's live, later | the scheduled-draft panel |
| 7 | Answers "why isn't it live?" | console output |

Every slide is pure CSS and type — there are no control-panel screenshots yet. When the CP settles,
screenshot slides can be added alongside these without redoing anything: copy the `.shot` /
`.viewport` pattern from `craft-appleseed-website/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#C2610F`, Jersey 20 for display, Inter for body.

Two things bite when editing:

- **`.points li` is a flex container.** Every text run either side of an inline tag becomes its own
  flex item, so `<li>… runs <em>after</em> the response</li>` lays out as three columns. Wrap the
  whole line in one `<span>`.
- **`background-clip: text` clips to the line box.** The gradient headline needs a `line-height`
  above 1 or its descenders are sliced off, which is invisible until you look at a `g`.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the clock with the dial punched out and the feet dropped. At watermark scale
  the feet are two hard-edged wedges hanging off an otherwise round silhouette; the ring and the
  bells are the part that still reads as an alarm clock across a whole slide.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
